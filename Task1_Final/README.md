\# Task 1 - Data Cleaning and Preprocessing



\## Project Overview



This project demonstrates data cleaning and preprocessing using Python and Pandas.



\## Dataset



The dataset contains customer information including:



\- Customer ID

\- Name

\- Age

\- Gender

\- City

\- Income

\- Purchase Amount

\- Purchase Date



\## Data Cleaning Performed



1\. Loaded the CSV dataset using Pandas.

2\. Inspected the dataset structure and data types.

3\. Identified missing values.

4\. Identified duplicate records.

5\. Removed duplicate records.

6\. Filled missing numeric values using median values.

7\. Standardized gender values.

8\. Standardized city names.

9\. Converted purchase dates into datetime format.

10\. Verified the cleaned dataset.

11\. Exported the cleaned dataset as a new CSV file.



\## Results



Original dataset:



\- Rows: 15

\- Columns: 8

\- Duplicate rows: 1

\- Missing Age: 1

\- Missing Income: 1

\- Missing Purchase Amount: 1



Final cleaned dataset:



\- Rows: 14

\- Columns: 8

\- Missing values: 0

\- Duplicate rows: 0
